# 전체 플로우 차트


![monggil_ui_p03.jpg](/portfolio/images/notion/몬길-star-dive-ui-분석/img-2.jpg)


▲ _전체 플로우 차트_

- 타이틀 → 게임 시작 → 로비 화면
- 로비 화면 → 퀘스트 목록 / 기능 UI
- 기능 UI → 전투 · 가챠 · 강화
    - **전투**: 파티 UI, 스테미나, 미니맵, 교체 쿨타임, 내 정보, HP, 적 UI, 약점 속성, 카운터, 그로기 → QTE → 전투 승리 or 패배 → 로비 화면
    - **가챠**: 픽업 캐릭터 및 아티팩트 획득, 확률 업, 가챠 재화
    - **강화**: 캐릭터 선택 → 몬스터링 강화
- 로비 화면 → 게임 종료

# 로비 분석


## 타이틀 화면


![monggil_ui_p05.jpg](/portfolio/images/notion/몬길-star-dive-ui-분석/img-3.jpg)


▲ _타이틀 화면_

1. **게임 종료**: 빠른 게임 종료를 위한 UI.
2. **기타 UI**: 공지사항과 환경설정을 같은 곳으로 묶어, 게임 시작 전 중요 정보를 확인하고 사전에 게임 설정을 완료할 수 있음.
3. **게임 시작**: 게임 시작 버튼은 아래쪽에 있으나, 화면 아무 곳이나 클릭해도 게임에 진입된다.

## 로비(필드) 화면


![monggil_ui_p06.jpg](/portfolio/images/notion/몬길-star-dive-ui-분석/img-4.jpg)


▲ _로비(필드) 화면_

1. **현재 위치**: 유저의 현재 위치.
2. **미니맵 & 기타 UI**: 직관적인 아이콘과 단축키로 유저의 클릭·터치 동선을 줄임.
3. **퀘스트 목록**: 퀘스트 목록과 진행 상황을 띄워 유저가 플레이할 방향성을 제시.
4. **현재 파티**
5. **기능 UI**: 핵심 기능은 외부로 노출되어 있고, 그 외 기능은 ESC 상호작용으로 숨겨져 있다.
6. **빠른 이벤트 배너**: 주요 이벤트에 빠르게 진입할 수 있는 배너.
    - ⚠️ 필드에서 실시간 전투를 할 때 시야를 방해한다. 다른 배너로 넘어가는 시각 효과까지 있어 방해 요소가 더 커진다.
7. **자동 이동**: 메인 퀘스트로 자동 이동하는 편의 기능.

## 몬스터링 관리 화면


![monggil_ui_p13.jpg](/portfolio/images/notion/몬길-star-dive-ui-분석/img-10.jpg)


▲ _몬스터링 관리 화면_

1. **목록**: 캐릭터 육성에 필요한 강화 목록.
2. **몬스터링 장착 효과**: 몬스터링 장착 시 스탯과 추가 효과를 직관적으로 보여 줌.
3. **장착 현황**: 사용 중인 몬스터링 확인 및 탈착 가능.
    - 클릭 시 탈착·합성·강화가 가능한 창으로 이동.
    - 3개까지 장착 가능.
    - 몬스터링의 레벨을 화면에 표시.
4. **관리**: 세부 관리로 이동하는 직관적 UI. 3번과 같은 기능.

## 몬스터볼 강화 화면


![monggil_ui_p14.jpg](/portfolio/images/notion/몬길-star-dive-ui-분석/img-11.jpg)


▲ _몬스터볼 강화 화면_

1. **강화 재료**: 육성에 필요한 재료 목록.
2. **정렬**: 레벨·등급으로 정렬. 내림차순/오름차순 가능.
3. **선택된 몬스터 볼 이미지**
4. **몬스터볼 레벨 및 스탯**
    - 강화 재료 선택 시 재료에 따라 경험치가 오르고, 최대치에 도달하면 다음 레벨로 상승.
    - 레벨 상승으로 스탯이 오르면 기존 스탯과 비교해 보여 줌.
5. **선택된 강화 재료**
    - 최대 10개까지 선택 가능.
    - 강화 전용 재료는 중첩 가능.
    - 재료의 이미지와 레벨을 표시.
6. **재료 자동 선택 및 해제**
    - 일정 성급 이하로 지정해 일괄 선택 가능.
    - 강화 전용 재료만 소모하도록 설정 가능.
    - 모두 해제 버튼으로 재료 전체 해제.
7. **강화**: 재화를 소모해 강화. 강화 전용 재료일수록, 성급이 높을수록 소모 재화량이 많아진다.

# 전투 시스템 분석


## 전투 HUD


![monggil_ui_p16.jpg](/portfolio/images/notion/몬길-star-dive-ui-분석/img-12.jpg)


▲ _전투 HUD_

1. **적 UI**: 체력, 그로기, 적 약점 속성, 몹 유형(보스·일반), 포획 가능 확률 등을 표기.
    - 체력이 100%에서 0%가 되면 처치.
    - 그로기는 0%에서 100%에 도달하면 특수 이펙트와 함께 보스 몬스터가 그로기 상태에 돌입.
    - 약점 속성으로 공격하면 추가 데미지가 들어가는 메리트.
2. **스테미나**: 전투 중 회피에 필요한 게이지. 회피 외 행동 중에는 서서히 차오름.
3. **파티**: 3명이 한 파티.
    - PC는 1·2·3번으로 교체, Space바로 빠른 스왑 가능.
    - 교체 후 기존 캐릭터로 다시 교체하기까지 쿨타임 존재.
4. **내 정보**: 내 캐릭터의 체력·레벨·타겟 표기. 특수 스킬 게이지가 있으면 체력 위에 고유 아이콘으로 표시.
5. **스킬**: (PC) Q, E, 좌클릭, 우클릭으로 구성된 스킬 UI.
    - 스킬 사용 시 쿨타임 존재.
    - Q는 궁극 스킬로 효과가 강력한 대신 게이지를 모아야 하는 디메리트가 있음.

## 미니맵 · 속성 · 캐릭터 · 자동 타겟


![monggil_ui_p17.jpg](/portfolio/images/notion/몬길-star-dive-ui-분석/img-13.jpg)


▲ _미니맵 · 약점 속성 · 캐릭터 · 자동 타겟_

1. **미니맵**: 주변 지도를 작게 보여 주고, 적군 위치를 빨간 점으로 강조.
2. **약점 속성**: 약점 속성에 맞는 캐릭터를 보유하면 데미지 우위를 가져감.
    - 속성: 바람, 번개, 얼음, 땅, 불 5가지 + 속성 데미지에 포함되지 않는 물리 속성.
3. **캐릭터**: 파티 캐릭터의 HP, 속성, 교대 쿨타임을 육안으로 확인 가능.
    - 교대 가능할 때 캐릭터마다 고유 대사가 팝업으로 떠서 교대 가능 상황을 인지시켜 줌.
4. **자동 타겟**: 빠른 액션으로 화면 전환이 잦아 적 위치를 식별하기 어렵기 때문에(혹은 모바일 환경에서 조작이 원활하지 않으므로) 적 위치에 따라 시점이 전환되는 기능.

## 카운터 · 그로기


![monggil_ui_p18.jpg](/portfolio/images/notion/몬길-star-dive-ui-분석/img-14.jpg)


▲ _카운터 타이밍 · 그로기 게이지_

1. **카운터**
    - 카운터 타이밍에 노란색 워닝 사인이 뜸.
    - (PC) Shift나 Space바 입력 시 카운터 성공.
    - 성공 시 대량의 그로기 게이지와 상당한 데미지를 가함.
    - 성공 시 캐릭터들의 교체 쿨타임이 모두 초기화.
    - 카운터로 교체 쿨타임이 줄어 타 게임보다 캐릭터별 온필드 타임이 비교적 짧다. 빠른 교체의 스피드함이 액션감을 만든다.
2. **그로기**
    - 데미지를 주거나 카운터에 성공하면 그로기 게이지가 쌓임.
    - 100% 도달 시 특수 이펙트와 함께 보스가 행동 불가 상태가 됨.
    - 그로기 상태 동안 캐릭터 교체 쿨타임이 짧아짐.
    - 빠른 스왑과 교체 스킬 공격으로 데미지를 빠르게 누적할 수 있음.

## QTE · 버스트 스킬


![monggil_ui_p19.jpg](/portfolio/images/notion/몬길-star-dive-ui-분석/img-15.jpg)


▲ _QTE · 버스트 스킬_

1. **QTE**: 그로기 게이지를 100% 채우면 나오는 QTE 연출. (PC) Space바로 발동, 이후 특수 연출.
2. **버스트 스킬**: QTE 이후 특수 연출과 함께 나오는 QTE 연출의 연장선. 강력한 데미지를 주며 보스는 그로기 상태에 빠진다.

## 가챠 메인 화면


![monggil_ui_p25.jpg](/portfolio/images/notion/몬길-star-dive-ui-분석/img-20.jpg)


▲ _가챠 메인 화면_

1. **가챠 배너**: 현재 픽업, 상시 캐릭터/아티팩트를 보여 줌. 썸네일과 남은 픽업 기간 등을 띄워 기간을 공지.
2. **가챠 재화**
    - 종류: 태초의 별(유료 재화), 별빛 수정, 운명의 나침반(픽업 캐릭터 전용), 기억의 나침반(픽업 캐릭터 아티팩트 전용), 약속의 나침반(상시 캐릭터·아티팩트 겸용).
    - 10회 뽑기 시 나침반류가 가장 먼저 소모되고, 부족분은 별빛 수정 → 태초의 별 순으로 추가 소모.
    - 태초의 별과 별빛 수정은 160개당 나침반 1개로 교환.
    - ⚠️ **개선점**: 태초의 별과 별빛 수정은 별개 재화라 서로 교환되지 않는다(타 게임은 보통 1:1 교환 가능). 가챠 재화가 약간 부족할 때 교환이 안 돼 추가 결제를 해야 하는 불편이 있으므로, 1:1 교환이 가능하도록 바뀌는 것이 좋아 보인다.
3. **캐릭터 이미지 및 속성**: 현재 픽업 캐릭터의 일러스트·속성·성급 표시. 일러스트를 중앙에 띄워 구매 욕구를 자극.

## 편의 UI · 확률 정보


![monggil_ui_p26.jpg](/portfolio/images/notion/몬길-star-dive-ui-분석/img-21.jpg)


▲ _편의 UI · 4성 픽업 · 확률 업 정보_

1. **편의성 UI**
    - 가챠로 나온 캐릭터에 따라 추가 재화 지급. 추가 재화로 뽑기 재화나 육성 재료 등을 구매 가능.
    - 모집 기록: 가챠 횟수 확인용.
    - 미리보기: 캐릭터의 스탯·스킬·3D 렌더링을 확인하고 구매 여부를 결정할 수 있음.
    - 확률: 가챠 확률 정보 제공.
2. **4성 픽업 캐릭터**: 최고 등급인 5성은 확률이 낮으므로, 성능은 다소 낮지만 쓸 만한 4성 캐릭터들의 확률이 올라간다.
3. **확률 업 정보**: 현재 픽업 캐릭터 확정 획득까지 남은 횟수 표기.
    - 기본 픽업 확률 1%. 캐릭터는 90회, 아티팩트는 80회에 확정 획득.
    - 76회부터 확률 추가 보너스(1회당 +6.6%)가 붙음.
    - 천장 잔여 횟수는 다음 픽업 배너로 이월.
