## 맡은 역할

5인 기획자 팀에서 시스템은 팀장이, UI/UX 기획은 제가 맡았습니다. 게임을 켜서 결과를 볼 때까지 유저가 거치는 화면 전체를 기획했습니다.

| 구역 | 화면 |
| --- | --- |
| 아웃게임 | 타이틀과 로고, 설정, 접속 화면, ESC 메뉴 |
| 로비 | 의상실, 수정구, 수련장, 스킬 도감, 출발 마법진 |
| 인게임 HUD | 라운드별 점령·레이스·코인 쟁탈, 미션 알림, 피격·타격 표시, Tab 현황판 |
| 라운드 흐름 | 시작 정보와 카운트다운, 라운드 결과, 최종 결과, 로딩 화면 |
| 소리 | 모든 화면에 들어가는 UI 효과음 29개 |

플레이테스트를 세 번(M1, M2, M3) 거치며 고쳤습니다. 시안 제작과 Unity 적용에는 Claude를 도구로 썼고, 무엇을 고를지는 기획서의 기준으로 제가 정했습니다.

### 늘 보이는 정보는 최소로

<p class="why">늘 보이는 정보는 스킬 칸, 점령 현황, 기절 게이지, 날아간 횟수 네 가지로 정했습니다. HUD만으로 모든 것을 표현하지 않습니다.</p>

| HUD에서 뺀 것 | 대신 보여 주는 곳 |
| --- | --- |
| 강공격 차지 게이지 | 크로스헤어 모양. 차지할수록 점이 원으로 커지고, 다 차면 톡 튀며 고리가 퍼짐 |
| 기절 상태, 공격 범위 부채꼴, 연타 카운터 | 캐릭터 애니메이션과 이펙트 |
| 피격 방향 표시 | 3인칭이라 화면으로 보임 |
| 마법 설명 | Tab을 누르는 동안만 말풍선으로. 마법은 얻을 때 무엇을 얻었는지만 알면 되기 때문 |

새 정보를 알려야 할 때는 아래 순서를 지켰습니다. 예를 들어 2R 피버 안내는 새 HUD를 만들지 않고 기존 예고 글씨와 미션 카드에 넣었습니다.

<ol class="stairs">
  <li><span>1</span>몸으로 느끼게 (캐릭터·카메라 연출)</li>
  <li><span>2</span>이미 있는 화면 자리에 넣기</li>
  <li><span>3</span>시작할 때 한 번만 설명</li>
  <li><span>4</span>그래도 안 되면 새 HUD 요소</li>
</ol>

### 화면의 자리로 의미를 나눈다

<p class="why">화면 가운데 큰 글자는 모두에게 일어나는 일에만 씁니다. 나만의 일은 가장자리에 둬서, 자리만 보고도 누구의 일인지 알 수 있게 했습니다.</p>

| 자리 | 무엇을 두나 |
| --- | --- |
| 가운데, 크게 | 모두에게 동시에 일어나는 일: 라운드 시작 3·2·1, 공통 미션 예고. 3·2·1도 공통 미션 예고와 같은 모양과 움직임을 써서, 가운데 큰 글자가 늘 같은 뜻으로 읽히게 |
| 왼쪽 위 | 모두의 순위인 점령 현황 |
| 왼쪽 아래 | 나의 상태: 기절 게이지, 날아간 횟수 |
| 오른쪽 아래 | 나의 스킬 |

### 1. 개요

#### UI 방향

- 깔끔하고 직관적인 UI. 판단이 갈리면 이 기준으로 본다.
- 난전에서 "내가 때렸다 / 내가 맞았다 / 저 사람은 지금 날릴 수 있다"가 0.1초 안에 읽혀야 한다.
- HUD만으로 모든 것을 표현하지 않는다. 기절 상태, 강공격 차지, 공격 범위 등은 캐릭터 애니메이션·VFX와 나눠서 보여 준다.
- 늘 보이는 정보는 최소로 두고, 나머지는 필요할 때만 뜨게 한다.

#### 테마와 UI 구분

연구에 지친 힘법사(지팡이로 물리 공격하는 마법사)들이 휴가지로 떠나는 이야기다. 스테이지마다 휴가지 테마가 다르고, 이번 스테이지(1~3R)는 워터파크다.

| 구분 | 내용 |
|---|---|
| 공통 UI | 타이틀 · 로비 맵 · 설정 · ESC 메뉴 · 안내 창. 스테이지가 바뀌어도 그대로 |
| 스테이지별 UI | HUD 아이콘 세트를 갈아끼운다. 워터파크 = 튜브·호루라기 |
| 일부 스테이지별 | 월드 UI, 연출 문구. 카운트다운은 공통, 장외 문구는 스테이지별 (예: "입수!") |

#### 공통 규칙

| 항목 | 규칙 |
|---|---|
| 인원 | 최대 4인. UI는 4인에 맞춰 고정하지 않고, 인원이 늘어도 배치가 깨지지 않게 만든다 (로비는 8명까지 고려) |
| 라운드 | 라운드별 UI(라운드 정보, 결과)는 갈아끼울 수 있게 만든다 |
| 화면 비율 | 16:9만 지원. 다른 비율은 검은 띠 |
| 언어 | 한국어 / 영어. 글자는 번역 표(UIStrings)로 넣는다 |
| 글자 | TextMeshPro. 제목용·본문용 글꼴을 나눠 쓴다 |
| 확인 창 | 버튼은 모두 "예 / 아니오". 나가는 동작은 모두 확인 창을 띄운다 |
| 봇 | 없음 (팀 결정) |
| 테마 이름 | UI 에셋·코드 이름에 테마 이름을 넣지 않는다 |

### 2. 전체 화면 흐름

```
[타이틀]
  │ 게임 시작
  ▼
[의상실 · 혼자 (문 닫힘)] ── 왼쪽 수정구 ──▶ [커스터마이징 화면] (언제든, 자유)
  │ 오른쪽 수정구 치기                                     ▲ 실패 · 취소
  ▼                                                        │

  ▼                                            ▼
[멀티 세션 · 문 열림 → 수련장 · 포털] ◀────────┘ ◀── 일정 시간 뒤 포털 근처로 자동 복귀 ──┐

```

### 3. 아웃게임

#### 3-1. 타이틀

로비 맵과 따로 떨어진 씬이다. 나가기·강퇴·연결 끊김 때 씬을 바꾸면 접속과 캐릭터가 깔끔하게 정리된다.

| 항목 | 동작 |
|---|---|
| 게임 시작 | 창 없이 바로 로비 맵의 의상실에서 시작 (혼자) |
| 설정 | 설정 창을 타이틀 위에 띄운다 (화면 전환 없음) |
| 나가기 | "나가시겠습니까?" 예 / 아니오 → 예면 게임 종료 |
| 버전 표시 | v_1.1부터. 작은 업데이트는 두 번째 숫자, 큰 업데이트는 앞 숫자 |
| 로고·배경 (10-20) | 게임 이름 R.A.M.P (Random Amazing Magic Party). 로고 = 점프대: 글자가 오른쪽으로 갈수록 올라가며 비스듬한 점프대 위에 섬, P만 분홍, 점은 노랑. 풀네임은 로고 아래 작게. 로고에 마우스를 올리면 커서가 방망이, 클릭하면 글자가 날아갔다 돌아오고 "깡! / 까앙! / 홈런!"이 뜬다 (안내 글자 없음). M1 바탕은 단색, 캐릭터 없음. |

닉네임 입력과 커스터마이징은 타이틀에 두지 않는다. 닉네임은 의상실의 접속 수정구, 외형은 커스터마이징 수정구에서 한다 (10-26).

#### 3-2. 로비 맵

게임 시작을 누르면 들어가는 3D 공간. 처음에는 혼자(개인 방)이고 의상실 안에만 있을 수 있다. 의상실의 접속 수정구로 방을 만들거나 친구 방에 참가하면(멀티 세션) 문이 열린다. 혼자 있던 맵이 그대로 방이 된다.

##### 첫 시작 (10-26 바뀜)

- 게임을 시작하면 항상 의상실에서 시작한다. 의상실과 로비 맵은 같은 맵이다.
- 시작 뷰: 정면에 닫힌 문, 양옆에 수정구가 한눈에 보인다. 왼쪽 = 커스터마이징 수정구, 오른쪽 = 접속 수정구. 보이는 수정구로 걸어가 자연스럽게 치게 한다. 안내 글자는 없다.
- 문은 멀티 세션에 들어가야만 열린다 (방 만들기·참가). 완료 기록은 없고 매번 닫힌 문으로 시작한다. 혼자(싱글)일 때는 의상실 안에서 커스터마이징·접속만 할 수 있다. 게임 시작은 2명 이상이라 싱글에서 할 일이 없기 때문이다.
- 커스터마이징은 자유다. 안 해도 기본 외형으로 멀티에 들어갈 수 있다.
- 닉네임은 접속 수정구에서 먼저 입력해야 멀티에 들어갈 수 있다 (아래 "닉네임").
- 참가자는 방장 맵의 의상실에 도착한다 (문은 이미 열려 있음).
- 의상실과 포털 사이에 수련장이 있다 (아래). 크게 배치한 포털로 시선을 유도한다. 포털 앞은 게임 시작(마법진) 전용이다.
- ~~처음엔 거울·커스터마이징 수정구 쪽을 보고, 커스터마이징을 확정해야 문이 열림, 두 번째부터 열린 문을 보며 시작~~ (→ 10-26: M1 플레이테스트에서 수정구를 쳐야 창이 뜨는 것과 방 만드는 곳(포털 앞)을 찾기 어려워해서 바꿈)

##### 수련장 (의상실 ~ 포털 사이)

- 멀티 세션에서만 갈 수 있다 (혼자 놀기도 방을 연 상태에서).
- 스킬 상자(마법 수정·선물 상자)와 허수아비가 평범하게 흩어져 있고, 자연스럽게 지나갈 수 있는 구조다. 세부 배치는 레벨 디자인에서 정한다.
- 들르지 않고 포털로 바로 갈 수 있다. 가는 길에 놓여 있어 자연스럽게 사용법을 익힌다.
- 허수아비는 기절시키면 날릴 수 있고, 날리면 한 번에 장외가 된다 (실전처럼 4번째가 아님). 3초 뒤 제자리에 다시 생긴다.
- 이동기(점프·구르기) 연습 구간은 두지 않는다.

##### 수정구 상호작용

| 항목 | 동작 |
|---|---|
| 오브젝트 | 상호작용 오브젝트는 모두 수정구 (접속 수정구, 커스터마이징 수정구). 둘 다 의상실 안, 문 양옆 (왼쪽 커스터마이징, 오른쪽 접속, 10-26). ~~옆에 용도를 보여 주는 장식을 둔다 (접속 = 포털 문)~~ |
| 여는 법 | 방망이질(좌클릭)로 친다. 별도 상호작용 키 없음. 스킬로는 열리지 않는다 |
| 기능 아이콘 | 수정구 위에 어느 기능인지 알려 주는 아이콘을 항상 띄운다. 커스터마이징 = 옷걸이, 접속 = 인터넷 모양(와이파이). 방망이 아이콘은 두지 않는다. 임시 3D 모델을 수정구 바로 위에 띄운다 (10-22). 10-26: 상호작용할 물건처럼 보이게 위아래로 천천히 둥둥 뜨고(폭 0.08m·2초 [임시]), 판판한 모양이라 늘 카메라 쪽을 본다(좌우 회전만), 어두운 곳에서도 보이게 자체 발광. ~~움직이지 않는다~~ |
| 칠 수 있을 때 | 방망이질 사거리 안에서 수정구를 바라볼 때만 크로스헤어가 방망이 모양으로 바뀐다. 차지 표시·타격 이펙트는 평소 크로스헤어와 같다. 내 화면에만 보이는 표시라 UI가 거리·방향을 계산한다 |
| 화면 | 친 사람에게만 뜬다. 여러 명이 동시에 열 수 있다. 화면에 붙는 UI로 먼저 만든다 |
| 닫기 | ESC, 닫기 버튼. 화면이 열려 있으면 ESC는 그 화면만 닫는다 |
| 열려 있는 동안 | 캐릭터 조작이 막힌다. 타격·스킬 효과를 받지 않고(맞는 모션은 나옴) 머리 위에 "설정 중" |

##### 접속 수정구 화면

| 상태 | 보이는 것 |
|---|---|
| 혼자 | 닉네임 입력칸(10-26) + 방 만들기 / 방 참가 → 참가 코드 입력. 닉네임이 규칙에 맞아야 방 만들기·참가 버튼이 눌린다. 참가 실패 안내도 이 화면에 |
| 방 안 (방장·참가자) | 닉네임 칸이 없어 바꿀 수 없다 (10-26) |
| 방장 | 참가 코드 + 복사 버튼("복사됨" 표시), 참가자 목록, 인원(예: 2/4), 강퇴 버튼 |
| 참가자 | 참가 코드, 참가자 목록 |

- 참가 코드: 6자리 영문 대문자+숫자. 붙여넣기를 지원하고, 엔터로 참가하며, 대소문자는 구분하지 않는다.
- 참가자 목록: 닉네임을 플레이어 색 글자로. 방장은 "방장" 글자 (~~왕관 아이콘~~ → 10-16: 왕관은 1등 표시라 방장에는 쓰지 않는다), 내 이름은 강조, 빈 자리는 "대기 중…".
- "혼자"에는 게임 시작 때 혼자 만든 잠긴 방도 포함된다 (다른 사람을 받는 방이 열렸는지로 나눈다). 참가에 실패·취소하면 혼자 로비로 돌아와 이 화면이 실패 이유와 함께 다시 열린다.
- 플레이어 색: 들어온 순서대로 배정. 캐릭터에 색을 칠하지 않고 이름 글자 색으로만 구분한다.
- 강퇴: 방장만, 확인 창을 거친다. 게임 중에는 강퇴할 수 없다.

##### 방 참가

```
[코드 입력 · 참가] → [혼자 로비 끊어짐] → [연결 연출 씬: 접속 중 · 15초] ── 성공 ──▶ [의상실 도착 (방장의 로비 맵, 10-26)]
        ▲                                          │ 실패 · 취소
        │ 다시 코드 입력                           ▼
[접속 화면 다시 열림 (실패 안내와 함께)] ◀── [실패 연출 → 혼자 로비로 돌아옴]
```

입장·퇴장은 글 안내 없이 도착 자리(의상실) 연출과 효과음으로만 알린다. ~~포털 문 앞 도착~~ (→ 10-26 의상실)

##### 게임 시작: 마법진

- 방에 있는 모두(최소 2명)가 마법진 위에 3초 서 있으면 게임이 시작된다. 시작 버튼은 없다.
- 시간은 포털 위 시계가 돌아가는 연출과 마법진이 채워지는 연출로 보여 준다. 따로 뜨는 카운트다운은 없다.
- 한 명이라도 내려오면 취소. 2명 미만이면 서 있어도 마법진이 반짝이지 않는다.
- 수정구는 마법진에서 멀리 두어, 수정구 화면을 연 채로는 마법진에 올라갈 수 없게 한다.

##### 닉네임

| 항목 | 규칙 |
|---|---|
| 입력 위치 (10-26) | 접속 수정구 화면 (혼자일 때). 입력해야 방 만들기·참가 가능. 멀티 세션에 들어간 뒤에는 바꿀 수 없고, 다음 접속 때(다시 혼자일 때) 바꿀 수 있다. 이 PC에 저장해 다음에도 들어 있다. ~~커스터마이징 수정구 화면, 방 안에서도 바꿀 수 있음~~ |
| 길이 | 2글자 이상, 12칸 이하 (한글 1자 = 2칸, 영어·숫자 1자 = 1칸) → 한글 2~6자, 영어 2~12자 |
| 쓸 수 있는 글자 | 한글·영어·숫자만 (띄어쓰기·특수문자·이모지는 입력되지 않게 막음, 10-16) |
| 규칙에 안 맞을 때 | 진행 버튼 비활성 + 입력칸 아래 실시간 안내 (문구 예: "2글자 이상 입력해 주세요", "한글 6자, 영어 12자까지 입력할 수 있습니다") |
| 중복 | 같은 방에 같은 이름이 있으면 뒤에 (2)를 붙인다 |
| 입력칸 | 비어 있으면 "닉네임을 입력하세요". 저장된 이름이 있으면 들어 있다 |
| 자음·모음 (10-17) | "ㅋㅋ"처럼 자음·모음만 입력해도 한글(2칸)로 쳐서 통과 (한글은 조합하며 입력돼 입력 단계에서 막을 수 없음) |
| 12칸 (10-17) | 12칸이 차면 더 입력되지 않게 막는다. 더 입력하려 하면 "한글 6자, 영어 12자까지 입력할 수 있습니다"를 2초 보여 준다 (인스펙터에서 바꿈). "2글자 이상 입력해 주세요"는 1글자일 때만 (비어 있으면 입력칸 안내 글자만) |

##### 커스터마이징 화면 (10-16 결정, 10-17 만듦, 외형 10-20)

| 항목 | 동작 |
|---|---|
| 여는 법 | 의상실의 커스터마이징 수정구를 친다 |
| 구성 (10-20) | 화면 전체를 꾸미기 무대로 바꾼다. 캐릭터는 화면 왼쪽, 제목 "의상실"은 캐릭터 위 (닉네임 입력칸은 10-26 접속 화면으로 옮김). 오른쪽 창 하나에 묶음(왼쪽 열) + 부위 이름·탭·모양 칸·색(오른쪽 열). 아래 오른쪽에 "처음 모습으로"·확정 버튼. 마법사 모자가 들어갈 자리를 위해 캐릭터 머리 위를 비워 둔다 |
| 묶음 (10-20) | 부위는 묶음으로 보여 주고, 묶음 안 부위는 탭. 머리(머리카락) / 얼굴(눈썹·수염·안경·가면) / 몸(상의·왼팔·오른팔) / 신발 / 피부. 모자·헤드폰은 화면에서 뺀다 (마법사 모자 모델이 들어오면 다시 봄). 부위가 하나뿐인 묶음도 탭 줄은 보인다. 묶음 표는 UI 데이터로 두고 부위 이름·모양은 부품 목록에서 읽는다 |
| 모양·색 (10-20) | 모양 칸은 '없음' 칸 + 모양 아이콘, 모양이 많은 부위(눈썹 30개)도 한 줄 4칸 + 스크롤. 고른 모양의 색이 둘 이상이면 색 동그라미 줄. 피부는 색만 |
| 글자 줄이기 (10-20) | 개수 글자(닉네임 "N / 12칸", 묶음 "N부위", "모양 N개 · 색 N개"), 색 줄 앞 "색" 글자, "끌어서 돌려 보기" 안내는 보여 주지 않는다. 캐릭터는 빈 곳을 끌면 돈다 |
| 처음 모습으로 (10-20) | 확정 전 고른 외형을 맨몸으로 되돌린다 |
| 확정 | 누르면 확인 창 "커스터마이징을 확정하시겠습니까?" [예/아니오]. 예 = 외형 저장·전달 → 창 닫힘. ~~닉네임 저장·전달, 완료 기록 저장, 처음이면 의상실 문이 열림~~ (→ 10-26) |
| 닫기 (10-26) | 처음부터 자유. 닫기 버튼은 없고 (10-20) ESC로 확정 없이 닫을 수 있다. 바꾼 게 있으면 확인 창(10-22), 고른 외형은 되돌린다. ~~처음 한 번은 확정해야만 닫힘~~ |
| 입력칸 부품 | 공용 입력칸 프리팹을 새로 만들어 쓰고, 접속 화면 참가 코드 칸도 같은 부품으로 옮긴다 (10-17) |
| 글자 (10-17) | 제목 "의상실", 확정 버튼 "확정", "처음 모습으로"(10-20). 번역 표에는 아직 넣지 않음 (임시로 프리팹 안) |

##### 방에서 나올 때

- ESC 메뉴로 나가기, 방장이 나감, 강퇴, 연결 끊김 → 안내 뒤 모두 타이틀로.
- 방장이 나가면 방이 없어진다. 방장 확인 문구: "나가시겠습니까? 모든 플레이어가 방에서 나가게 됩니다."
- 최종 결과 뒤에는 일정 시간이 지나면 방을 유지한 채 모두 로비 맵의 포털 근처로 자동 복귀 (10-26).
- 방장이 방 닫기(접속 화면)를 하면 혼자 방으로 돌아가고, 의상실 문이 닫히며 의상실로 옮겨진다 (10-26).

### 4. 인게임 HUD

"내 상태"와 "조준·타격"은 모든 라운드 공통이고, "라운드 정보"는 라운드마다 갈아끼운다. 아이콘 세트는 스테이지별로 바꾼다.

#### 4-2. 내 상태 (공통)

| 요소 | 동작 |
|---|---|
| 마법 칸 2개 | 아래 가운데, 박스 하나로 묶고 다음 칸은 조금 작게. 먼저 주운 순서대로 사용, 앞 칸이 비면 뒤 마법이 당겨진다. 얻으면 칸이 반짝인다. 평소엔 설명 없음 (Tab을 누르면 말풍선). 칸에 마법 아이콘 그림 + 마법 이름 (10-22, 원형으로 잘라 칸 크기의 70%). 그림은에서 스킬 데이터의 아이콘 이름으로 찾고, 없으면 칸을 비운다 |
| 버프 칸 1개 (Q) | 오른쪽 아래, 마법 칸보다 조금 크게. 아이콘은 오른쪽 끝, 이름·설명은 아이콘 왼쪽에 상시 표시. 없으면 빈칸 |
| 버프 사용 중 | 남은 시간은 크로스헤어 아래 게이지가 줄어드는 것으로 보여 준다. 쓴 뒤 버프 칸은 빈칸(새로 주울 수 있음). 적용 중에 새 버프를 주우면 칸이 잠김 표시(어둡게 + 자물쇠), 그때 Q를 누르면 칸이 빨갛게 한 번 반짝인다 |
| 키 배지 | 칸 아래에 키 표시: 마법 앞 칸 우클릭 그림, 다음 칸 "다음", 버프 Q, 구르기 Shift. 조작키를 바꾸면 배지도 따라 바뀐다 |
| 구르기 대기시간 | 마법 박스 옆, 막대가 차오른다 (임시). System 값이 생기기 전까지는 자리만 둔다 (10-15) |
| 내 기절 게이지 | 좌하단. 맞을수록 차오르고 꽉 차면 기절. 4칸 나눔, 내 게이지는 연한 파랑(다른 플레이어는 녹색). 75% 노랑 규칙은 쓰지 않고, 대신 기절 위험이면 화면 가장자리가 빨갛게 깜빡인다 (기준 75%는 임시, 10-15) |
| 내가 기절했을 때 | 테두리·바가 빨강, 꽉 찬 바가 줄어들며 회복까지 남은 시간을 보여 준다. 바 안 글자 "회복 중" |
| 날아간 횟수 | 좌하단 패널 윗줄, 튜브 3개. 날아갈 때마다 하나씩 회색으로, 3번 다 잃으면 호루라기("다음에 날아가면 장외"). 부활하면 튜브 3개로 돌아온다 |
| "장외 위기" | 3번째로 날아간 뒤 일어나는 순간 내 화면에만 한 번. 호루라기 + "장외 위기" 글자가 떴다가 좌하단 패널 쪽으로 움직인다 |
| 못 주울 때 | 칸이 가득 차면 HUD가 아니라 스킬을 얻는 오브젝트 위에 "획득 불가!"가 뜬다 |

#### 4-3. 조준·타격 피드백 (공통)

##### 크로스헤어와 강공격 차지

따로 차지 게이지를 두지 않고 크로스헤어 자체로 차지를 보여 준다. 차지는 캐릭터 애니메이션·VFX로도 보인다. 쓸 값:,,.

| 단계 | 크로스헤어 |
|---|---|
| 평소 | 흰 점 + 어두운 외곽선. 약공격(0.2초 안에 뗌)은 표시 없음 |
| 차지 중 | 점이 흰 원으로 점점 커짐. 흰 빛 알갱이가 원으로 빨려 들어감 |
| 풀차지 (0.7초) | 기본 점 크기로 돌아가며 톡 튀고, 흰 고리가 한 번 퍼짐 |
| 풀차지 유지 | 점이 떨림. 강공격이 저절로 나가는 순간(풀차지 뒤 1.5초)에 가까울수록 세게 떨림 |
| 풀차지로 놓음 | 점이 고리로 퍼지며 사라지고, 휘두르기가 끝날 때(0.45초)까지 비어 있다가 다시 보임 |
| 덜 찬 상태로 놓음 | 터짐 없이 점으로 돌아옴 |

시간 값은 값을 따른다 (위 숫자는 지금 값).

로비 맵에서 방망이질 사거리 안의 수정구를 바라보면 점 대신 방망이 모양이 된다. 차지·터짐·타격 이펙트는 그대로 같다.

#### 4-5. Tab 현황판 (10-16 결정)

- Tab을 누르고 있는 동안만 뜨고 떼면 닫힌다. 조작키 변경 목록에 넣는다. 다른 화면이 열려 있으면 뜨지 않는다.
- 위치: 위쪽 가운데, 남은 시간 아래 (화면 가운데·크로스헤어와 아래쪽 말풍선 자리를 비워 둔다).
- 모든 라운드 공용 한 장. 라운드마다 다른 글자(모드 이름·승리 조건·목표 칸 이름)는 라운드 정보 데이터에서 가져온다.
- 제목: "ROUND 1 점령전" + 아래 승리 조건 한 줄 (예: "점령지를 지켜 코인을 모으세요").
- 한 줄: [왕관] 이름 | 지난 라운드까지 | 라운드 목표 | 미션. 지난 라운드까지 = 룬 코인, 라운드 목표 = 1R 점령 시간, 미션 = 결과 표시. ~~이번 라운드(합계, 굵게)~~ → 10-19 뺌.
 - 라운드 목표 = 1R은 점령 시간 (좌상단 점령 현황과 같은 "0:52" 형식, 10-19). ~~이번 라운드에 목표로 얻은 코인~~ → 코인은 결과 화면에서 처음 보여 준다. 지난 라운드까지 칸은 코인 그대로 (이미 앞 결과 화면에서 공개된 값). 2R부터 목표 칸에 무엇을 보일지는 라운드마다 정한다.
 - 미션 = 금액 대신 미션마다 결과만 보여 준다 (10-19). 1R은 미션이 3번(15·75·135초)이라 3칸 고정: 아직 결과 없음(진행 중 포함) / 성공 / 실패(흐리게, 빨강은 기절 색이라 안 씀). 진행 중 표시는 따로 없음 (모두 같은 순간에 미션을 받고, 내 진행은 미션 칸에 보임). M1 기준.
 - 이유: 이번 라운드 코인(점령·미션)을 Tab에서 숨겨 결과 화면에서 처음 공개 → 역전의 재미. 결과 화면 연출(합산·순위 이동)은 그대로 둔다. 점령은 좌상단과 같은 점령 시간으로 보여 준다 (10-19).
 - 이름 칸은 닉네임 최대 길이(영어 12자)에 맞춘다.
- 정렬: 입장 순서. 내 줄은 테두리로 강조.
- 왕관 = 경기 중 선두 (동점이면 없음). 머리 위 선두 왕관과 같은 뜻이다. 1R 왕관 = 점령 1등 (10-19 결정). 돈(점령 + 미션) 합산은 마지막 결과 화면에서. System이(10-19)에서 점령 1등으로 바뀜 (점령 시간이 같거나 모두 0초면 왕관 없음). UI는을 그대로 읽는다.
- 로비 맵: 제목 "참가자 N/4" + 줄마다 플레이어 색 동그라미 · 이름 · (방장이면 줄 오른쪽 끝에 "방장" 라벨). 코인 없음. 빈 자리는 보여 주지 않고, 들어온 사람 수만큼 판이 늘어난다 (10-19). 최대 인원(4)은 System 값으로 읽는다. ~~맨 앞 칸에 "방장" 글자, 이름만 (제목·코인 없음)~~
- 모양 (10-19): 바탕 있음 (아웃게임 B안 유리 창). 판 없는 F안 방식은 다른 플레이어 머리 위 표시와 겹쳐 뺌.. 디자인 기준은 컨플루언스 [UI] 8. 디자인.
- 마법 설명 말풍선 (마법 박스 바로 위): 두 칸 다 있으면 말풍선 하나를 세로줄로 좌우로 나눈다 (왼쪽 = 앞 칸, 같은 크기, 설명이 길면 줄만 늘어남). 한 칸만 있으면 한 칸짜리를 가운데 정렬 (10-19, ~~그 칸 위에~~). 꼬리(뾰족한 부분) 없음 (10-19). 없으면 안 뜬다. 문장은 마법 데이터의 설명.

#### 4-6. 룬 코인 표시 (10-16 결정)

코인 이름은 룬 코인(RuneCoin). 최종 승리는 3R 동안 룬 코인을 가장 많이 모은 사람이다 (라운드마다 승자는 따로 있다). 1R은 점령과 개인 미션으로 계속 늘고, 2R부터는 다른 방식으로 받는다. 게임이 끝나면 개인 보유 코인으로 바뀐다 (상점은 M2). 로비 맵에서는 보여 주지 않는다.

| 곳 | 보여 주는 것 | 연출 |
|---|---|---|
| HUD (우측 상단) | 이번 라운드에 얻은 내 룬 코인 (점령 현황이 점령 시간이라 이 칸은 둔다, 10-19) | 얻을 때마다 숫자가 올라가고(0.5초, 임시), 칸이 살짝 커졌다 돌아오고, "+N"이 떠올랐다 사라진다. 소리 없음 |

#### 4-7. 미션 (10-18·10-19 결정, System 이름 "임무")

- ~~처음에 화면 가운데 "개인 미션!"으로 떴다가 오른쪽 맵 기믹 자리로 옮겨 간다~~ (→ 10-18 바뀜)

### 6. 공통

#### ESC 메뉴

계속하기 / 설정 / 타이틀로 나가기 / 게임 종료. 로비 맵(혼자·방 안)과 게임 중 모두 같은 메뉴. 멀티 게임이라 열어도 게임은 멈추지 않는다. 나가기·종료는 확인 창을 거친다. 결과 화면 동안에는 열리지 않는다 (10-26).

#### 예외 상황 안내

상황마다 창을 따로 만들지 않고, "문구 + 버튼" 안내 창 하나에 내용만 바꿔 띄운다. 접속 수정구 앞에서 생기는 안내는 접속 화면에 띄운다.

| 상황 | 뜨는 곳 | 문구 | 이후 |
|---|---|---|---|
| 코드가 틀림 | 접속 화면 | 방을 찾을 수 없다는 안내 (문구 예) | 다시 코드 입력 |
| 방이 꽉 참 | 접속 화면 | 인원이 가득 찼다는 안내 (문구 예) | 다시 코드 입력 |
| 이미 시작된 방 | 접속 화면 | 들어갈 수 없다는 안내 (문구 예) | 다시 코드 입력 |
| 접속 실패 (15초) | 접속 화면 | 연결 실패 안내 (문구 예) | 다시 코드 입력 |
| 방장이 나감 | 안내 창 | "호스트가 종료되었습니다." [확인] | 타이틀로 |
| 강퇴당함 | 안내 창 | 강퇴되었다는 안내 (문구 예) | 타이틀로 |
| 내 연결이 끊김 | 안내 창 | 연결이 끊겼다는 안내 (문구 예) | 타이틀로 |
| 방장 나가기 확인 | ESC 메뉴 | "나가시겠습니까? 모든 플레이어가 방에서 나가게 됩니다." | 예면 방이 없어짐 |

| 제목용 | 학교안심 마법사 (후보) | 크고 짧은 글자에만 |

### 7. 튜토리얼

따로 떨어진 튜토리얼은 없다. 방벽으로 막힌 튜토리얼 길도, 이동기 연습 구간도 없다 (v0.3의 방벽 튜토리얼 길 대신 이 방식, 10-15 결정). "플레이어 안내는 게임 안에 넣는다"는 마일스톤 요구사항은 로비 맵으로 채운다.

| 순서 | 내용 |
|---|---|
| ① 의상실 (10-26) | 정면에 닫힌 문, 양옆 수정구(왼쪽 커스터마이징·오른쪽 접속)가 보이는 뷰로 시작해 수정구를 치도록 유도한다. 커스터마이징은 자유, 접속 수정구에서 닉네임을 정하고 멀티 세션에 들어가면 문이 열린다. 참가자는 방장의 의상실에 도착 |
| ② 수련장 | 의상실과 포털 사이에 스킬 상자·허수아비가 흩어져 있다. 건너뛸 수 있지만 가는 길에 있어 자연스럽게 써 본다. 허수아비는 날리면 바로 장외, 3초 뒤 다시 생김 |
| ③ 아이콘으로 알림 | 따로 안내 글은 없다. HUD 스킬 칸의 키 배지(우클릭·Q·Shift), 수정구 위 기능 아이콘(옷걸이·인터넷), 칠 수 있을 때 방망이 모양 크로스헤어 |
| ④ 포털 | 크게 배치해 시선을 끈다. 포털 앞은 게임 시작(출발 마법진) 전용 (10-26, ~~포털 앞 접속 수정구, 참가자는 포털 앞 도착~~) |

</details>

## 느낀 점

- HUD는 정보를 다 보여 주는 곳이 아니었습니다. 상태는 캐릭터 연출로 나눠 보여 주고, 늘 보이는 정보를 줄였을 때 플레이테스트 반응이 가장 좋았습니다.
- 조건을 바꾸지 않아도 이유를 보여 주는 것만으로 막힘이 풀렸습니다. 의상실 문은 여는 방법이 아니라 "왜 잠겼는지"가 안 보이는 게 문제였습니다.
